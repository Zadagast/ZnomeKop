# Attribution

All ZnomeKop art is generated deterministically by `tools/make_tiles.py`.

Creature sprite generation in `tools/psg.py` is a Python port of the
mask/mirror/outline algorithm from
[pixel-sprite-generator](https://github.com/zfedoran/pixel-sprite-generator)
(MIT License, (c) 2014 Zelimir Fedoran), itself based on Dave Bollinger's
"Pixel Spaceships" technique.
